# Flaw sweep inventory — every way Rivet stops, gates, wedges, or drops work

Worktree `~/workspace/rivet-flaws`, branch `flaw-sweep`, based on
`origin/batch/surface-fix` at `6f9f78adaf462b8daef3e539c7375084f36bd134`
(versionName 1.5.0 / versionCode 35, untouched). This inventory was written
before any fix. dsh evidence is from the shipped code at
`~/workspace/dsh-cli/node_modules/@deepseek-ai/`; refs are file:line in that
tree.

Tier: **S** = session-blocking (ends the turn, wedges a run, or refuses all
commands); **T** = tool-local (one call fails cleanly and the model can adapt);
**D** = silent drop, no honest result. "Fixed" is updated in Phase 2.

Verdict vocabulary from the brief: **COPY** dsh behaviour; **DELETE** (dsh has
nothing like it); **PROTECTS** (a real invariant that dsh reaches another way,
named).

## E. What each headline fix does now

1. **Loop banner**: `NoProgress` (deterministic failure and unchanged-read
   variants), `RunawayGuard`, `RuntimeBlocked` and `CapabilityBlocked` no longer
   exist as stop reasons. The agent loop is unbounded like
   `dsh-agent-loop/src/agent.ts`; a repeated call gets an advisory
   `repeat_reminder` context event at counts 3/5/8, copied from
   `dsh-repeat-tool-reminder/src/index.ts`. Tool and policy failures are
   correlated tool results and the model continues.
2. **Pending-changes block**: the startup banner and the command/terminal/
   process sync gates are gone. `runCommand` settles what it can and runs in the
   current worktree; a remaining per-file disagreement is reported in the
   result (`sync`, `sync_path`, `sync_conflict_paths`) instead of refusing the
   command. Undo becomes best-effort: a checkpoint that cannot be prepared
   leaves the mutation without an undo row and surfaces the existing Broken
   notice at turn end, rather than refusing the write.
