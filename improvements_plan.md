## Design

The phone is the workbench. Give each utility page a clear first action or current state, then a set of tools the user can open as needed. Read from the left icon rail down to actions and real status. Use one raised surface for the lead action when a page has one. Let disclosure rows sit directly on the background, divided by hairlines. Keep Home’s palette and composition.

| Role | Light | Dark |
| --- | --- | --- |
| Work surface | `#F4F5F3` | `#1A2020` |
| Lead inset | `#FBFCFA` | `#212A29` |
| Ink | `#182321` | `#F0F5F3` |
| Secondary | `#495C57` | `#BCD0CA` |
| Press and hover layer | `#E9EDEB` | `#283230` |
| Action and focus | `#225F6B` | `#91CBD2` |

Use existing theme outlines for rules. Keep the existing platform sans and its 28/34 semibold title, 15/22 row title, 15/23 reading text and 13/19 metadata. Use monospace only for paths and commands. Work in a 4 dp rhythm with 20 dp outer gutters, 16 dp group breaks, 12 dp between glyph and text, and 48 dp minimum interactive height. Use 9 dp for icon insets and 14 dp for a lead surface. Flat body, raised lead, floating only where the app already uses a popup. Repeat the icon rail and disclosure geometry across pages, with a 2 dp focus boundary. Use the current 24-unit stroked icon family and add purpose-built paths where a glyph is absent.

```text
Portrait                           Wide
< Phone access                     < Phone access
[ screen ] Screen capture          [ screen ] Screen capture | [ folders ] Granted folders
[ share  ] Share to Rivet   >      [ share  ] Share to Rivet > | [ command ] Termux bridge >
[ folders] Granted folders >       [ addon  ] Phone add-on >  |
[ command] Termux bridge   >
```

A generic settings design would put an icon and a long explanation on each identical card. Review against this brief led to one current-object or first-action surface, a flat rail for the rest, and an explicit disclosure boundary. The rail gives Projects, a model catalogue, and temporary tools a common grammar while each leads with different real state. The small reasoning selection signal is the most expressive moment. Skip page decoration, permanent explanations, extra navigation, gradients, stock illustration, and decorative motion.

Motion comes from `ui/Theme.kt`: 240 ms page and pane travel, 200 ms disclosure and sidebar, 160 ms press/focus, shared ease-out settling curve, and a 300 ms linear beat for compacting dots. Use bounded clips or layer transforms that settle at offset zero and scale one. Folds may change the height they disclose, and split preview reserves the target layout. Honor system animation scale, including static zero-scale states. Existing chat turn-fold appearance and behavior stay in place. Check keyboard order, 360 dp widths and landscape on a phone, including enlarged text.
