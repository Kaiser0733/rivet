# Fieldnote Assistant

A small chat app with offline demo replies and an optional OpenAI-compatible model.

Open `index.html` to try the demo without a key. For live replies, open Model settings, enter your endpoint, model name and key, then turn off offline demo replies. Your endpoint must support browser requests (CORS). Some endpoints refuse local-file requests, in which case you can use Rivet's project preview and allow its origin on your endpoint.

Ask Rivet to change the name and style, add a personal welcome message or save conversations on your device.
